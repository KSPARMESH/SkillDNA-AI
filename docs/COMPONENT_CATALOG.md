# SkillDNA AI UI Component Catalog

## Global Components (`src/components/common/`)
* **Header**: Responsive navigation bar with glassmorphic backdrop filter and user profile menu.
* **Footer**: Copyright banner and social links.

## Dashboard Widgets (`src/components/dashboard/`)
* **SkillDnaHeroScore**: Interactive 6-dimensional radar score gauge.
* **CareerReadinessWidget**: Role match qualification progress bar.

## AI Workspace Components (`src/components/ai/`)
* **AiMentorChat**: Chat interface with real-time AI response streaming.

## Recruitment Widgets (`src/components/recruitment/`)
* **CandidateCard**: Recruiter talent scorecard with verified proof-of-work badges.
