# SkillDNA AI Production Deployment Handbook

## Target Infrastructure

- **Frontend**: Vercel (`https://skill-dna-ai-frontend.vercel.app` - Next.js 14)
- **Backend API**: Render Web Service (`https://skilldna-backend-ii5w.onrender.com` - Express.js REST API)
- **Database**: Supabase Managed PostgreSQL 16 (Prisma ORM)
- **AI Engine**: Google Gemini 3.7 Flash API
- **Asset Storage**: Cloudinary Media Storage
- **CI/CD & Pre-commit**: GitHub Actions & Husky v9

For full deployment instructions, environment variable references, and post-deployment validation steps, see [DEPLOYMENT.md](file:///E:/KSP/Projects/SkillDNA-AI/docs/DEPLOYMENT.md).
