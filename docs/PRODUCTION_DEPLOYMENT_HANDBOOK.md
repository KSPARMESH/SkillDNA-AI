# SkillDNA AI Production Deployment Handbook

## Target Infrastructure
* **Frontend**: Vercel (Next.js 14)
* **Backend API**: Railway / Docker Container
* **Database**: Managed PostgreSQL 16
* **Cache**: Managed Redis 7
* **Reverse Proxy**: NGINX (`infrastructure/nginx/nginx.conf`)
* **CI/CD**: GitHub Actions (`infrastructure/ci-cd/github-actions.yml`)
