# SkillDNA AI GDPR & Data Privacy Compliance Handbook

## Compliance Policies
* **Data Subject Access Request (DSAR)**: Users can request a complete export of PII data via `/api/v1/users/me/export`.
* **Right to be Forgotten**: Triggering soft-delete scrubs PII fields from PostgreSQL 16 database within 30 days.
* **Consent Management**: Explicit consent required for third-party GitHub / LeetCode API data ingestion.
