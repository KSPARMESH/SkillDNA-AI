# SkillDNA AI Next.js 14 Frontend Application (`@skilldna/frontend`)

This package provides the modern, responsive web application for SkillDNA AI built with Next.js 14 (App Router), React 18, TypeScript, and Tailwind CSS.

## Features
* **Design System**: Rich dark-mode glassmorphism aesthetics, soft glow accents, responsive grids.
* **Hero Score Gauge**: Interactive SkillDNA Score visualization.
* **AI Workspace**: AI SkillDNA report viewer, Resume Analyzer, Portfolio Reviewer, and AI Mentor Chat interface.
* **Recruiter Directory**: Talent discovery matrix with verified proof-of-work badges.
* **SkillDNA Wrapped**: Technical growth recap.
